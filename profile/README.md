# Bhatt-Duchene Group

The Computational and Mathematical Global Health Group, in the Section for Health Data Science and AI at the Department of Public Health, University of Copenhagen.

We build mathematical, statistical and machine learning tools to answer questions about human health and evolution, from infectious disease epidemiology to phylogenetics.

- **Website:** https://sbhattlab.github.io
- **Software:** [phylo2vec](https://github.com/sbhattlab/phylo2vec), a library for vector-based phylogenetic tree manipulation
- **Global Pathogen Analysis Platform (GPAP) AI Research:** https://gpap-project.github.io
